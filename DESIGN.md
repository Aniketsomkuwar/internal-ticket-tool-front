## Overview

**Creative North Star: "The Productive Console"**

A deliberately small and direct system where every screen is a working screen: no mocked data, no placeholder panels, no decorative icons.

## Colors

- **Primary** (#1d4ed8): Used for primary actions and highlights.
- **Neutral Background** (#ffffff): Main application background.

**Display Font:** Inter, sans-serif
**Body Font:** Inter, sans-serif

## Layout

Standard dense application layout for productivity.
